FIXONCE AI Android v0.6.0

Что нового:
- 46 встроенных справочных тем.
- Поиск по ключевым словам с локальной адаптацией весов по оценкам «Помогло / Не помогло».
- Пользователь может добавлять собственные инструкции.
- Экспорт и импорт личной базы знаний JSON.
- Всё хранится локально на устройстве; приложение работает офлайн.

Что это НЕ:
Это не GPT, не генеративная языковая модель и не копия весов GPT.
Отзывы меняют приоритет поиска по темам, а не обучают большую нейросеть.
Нет OCR, анализа изображений, автоматического перевода, облачной синхронизации,
автоматического создания нейросетей и полноценного свободного диалога.

Получение APK с Android:
1. Скачай и распакуй ZIP.
2. Создай репозиторий Public на https://github.com/ с названием fixonce-ai.
3. Add file -> Upload files. Загрузи содержимое папки проекта, сохранив структуру.
   В корне должны быть app/, .github/, settings.gradle.kts и build.gradle.kts.
4. Commit changes.
5. Открой Actions и дождись успешного запуска Build FIXONCE AI APK.
6. В запуске найди Artifacts и скачай FIXONCE-AI-debug-APK.
7. Распакуй artifact ZIP и установи app-debug.apk на Android.

Workflow уже настроен в .github/workflows/build-android.yml.
Не загружай в публичный репозиторий секреты, токены или пароли.

Package: com.fixonce.ai
Для Google Play потребуется отдельная release-сборка AAB, подпись, политика конфиденциальности
и соблюдение требований Play Console. Debug APK не предназначен для публикации.
